# otus-team-1

Graduation project in C#

Обоснование предложения проекта, как дипломной работы по теме «Планирование отпусков» или «Обучающую платформу».

Для дипломного проекта на C# считаю важным учесть три фактора: скорость разработки, демонстративность и вес в резюме.
На первый взгляд кажется, что проект будет классический Enterprise веб-приложения, но данный выбор идеально ложится на стек .NET.
Проект можно масштабировать с простого сайта, а закончить микросервисами и обкатывать все уроки с курса.

Плюсы за:
  Планирование отпусков:
    - решает реальную бизнес-задачу  (учет графиков, пересечений отпусков, согласований)

  Обучающая платформа:
    - понятная структура из личного кабинета (студент/преподаватель), курсов, тестов, прогресса.
