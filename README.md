# otus-team-1

Graduation project in C#

Обоснование выбора (предложения) проекта, как дипломной работы.

Для дипломного проекта на C# считаю важным учесть три фактора: скорость разработки, демонстративность и вес в резюме.
На первый взгляд кажется, что проект будет классический Enterprise веб-приложения (Backend на ASP.NET Core, работа с базами данных через Entity Framework Core, архитектура REST API).
Данный выбор идеально ложится на стек .NET. Наставники сразу увидят: проектирование базы данных (пользователи, курсы, бронирования, календари).
Проект можно масштабировать с простого сайта, а закончить микросервисами.
